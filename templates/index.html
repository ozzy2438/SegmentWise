How it works

1
Data Upload

Upload the CSV file containing your customer data. It is recommended to use a file with at least 3 columns (Customer ID, Order Date, Amount).

2
Data Processing

The system automatically cleans, preprocesses your data, and prepares it for segmentation. If possible, the RFM (Recency, Frequency, Monetary) analysis is applied.

3
Segmentation

Your customers are segmented into groups based on similar behavioral patterns using the K-Means algorithm. You can optionally specify the number of segments or let the system find the optimal number.

4
Results and Recommendations

Detailed analyses, visualizations, and artificial intelligence-supported marketing recommendations are created for each segment.

How to use
1. Data Format

The system works best with CSV files in the following format:

  • Customer ID or Unique Identifier
  • Order/Transaction Date
  • Order/Transaction Amount
  • Product Information or Order Quantity (optional)
  • Demographic information (optional): Age, Gender, Location, etc.
2. How to determine the number of segments?

You can manually set the number of segments to a value between 2 and 10. If you leave it blank, the system will automatically determine the optimal number of segments using the Silhouette score and Elbow method.

3. What do the segments mean?

Segments are customer groups with similar behavior and/or demographic characteristics. For example:

  • High-Value Regular Customers
  • Customers who shop occasionally
  • New Customers
  • Customers at risk of attrition
4. Troubleshooting

If you encounter an error during the analysis:

  • Ensure the CSV file is in the correct format
  • Ensure the date column is in a valid date format
  • Ensure the numerical values are in the correct format
  • Large files (>100MB) may take longer to process
