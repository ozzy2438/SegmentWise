How to Use
Data Requirements
  • Upload your customer data in CSV format
  • Your file should contain customer ID, date and amount
  • Demographic data is optional but recommended
Analysis Process
  • Data is uploaded and cleaned
  • Segmentation is performed with K-Means
  • Recommendations are created for each segment
Frequently Asked Questions

You can determine the number of segments yourself or allow the system to automatically find the optimal number of segments. The system calculates the optimal number of clusters using the Silhouette Score and Elbow Method.

It is recommended to have the following data: customer ID, order date, order amount, and possible demographic data (age, gender, location, etc.). The system performs RFM (Recency, Frequency, Monetary) analysis to improve the quality of segmentation.

The system analyzes the characteristics of each segment and creates personalized marketing strategies, communication channels, and campaign recommendations using artificial intelligence. These recommendations are based on the segment's shopping behavior, demographic characteristics, and other features.
